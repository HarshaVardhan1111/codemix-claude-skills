# Tanglish glossary

Spellings vary; match by sound. Meaning depends on context — always read the whole sentence.

## Time
| Tanglish | Meaning |
|---|---|
| inniku / innaikku | today |
| naalaikku / nalaiku | tomorrow |
| nethu / nethiku | yesterday |
| ippo / ipo | now |
| apram / aprom / appuram | later / after that |
| sikkiram / seekiram | soon / quickly |
| kaalaila | in the morning |
| saayangalam / evening la | in the evening |
| ...kulla (friday kulla) | by / within (by Friday) |
| ...ah (3 days ah) | for (for 3 days) |

## Need, can, done
| Tanglish | Meaning |
|---|---|
| venum / vendum | need / want |
| vendaam / venam | don't want / no need |
| mudiyum | can / possible |
| mudiyala / mudiyathu | can't / unable (also: too tired, can't bear it) |
| mudinjiduchu / mudinjithu | finished / done |
| iruku / irukku | there is / have / is |
| illa / illai | no / not / don't have |
| theriyum | know |
| theriyala | don't know |
| puriyala | don't understand |
| aagum | will happen / will be (late aagum = will be late) |
| aagala | didn't happen / not done |

## Actions (+ "pannu" = do)
| Tanglish | Meaning |
|---|---|
| pannuren / panren | I'll do |
| pannitten | I did / I've done |
| pannunga | please do (polite) |
| pannanum | need to do |
| check panni sollunga | please check and tell me |
| sollunga | please tell |
| sollu | tell (casual) |
| kudunga | please give |
| anuppunga | please send |
| anupparen / anuppuren | I'll send |
| anuppitten | I've sent |
| varen / varuven | I'm coming / I'll come |
| vara mudiyathu | can't come |
| paathukaren | I'll take care of it / I'll handle it |
| paakalam | let's see / let's meet |
| wait pannunga | please wait |

| Tanglish | Meaning |
|---|---|
| udambu sari illa | not feeling well |
| kaichal | fever |

| seri / sari | okay |
| kandippa | definitely |
| thappu | mistake / wrong |
| mannichidunga | sorry / please forgive me |
| nandri | thank you |

## Grammar endings
| Ending | Meaning |
|---|---|
| -la | in / at (office la = at the office) |
| -ku | to / for (client ku = to the client) |
| -oda | with / of |
| -um | also / and |
| -nu | quote marker ("X-nu sonnaru" = he said X) |
| -nga / -unga | polite form (use respectful English) |

## Address words (set the tone)
| Word | Tone |
|---|---|
| sir / madam / anna / akka (to senior) | respectful |
| da / di / macha / bro / dei | casual, close friend — write casual English, drop the word |
| amma / appa | mother / father |
